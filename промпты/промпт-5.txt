Улучши внешний вид PDF-чеков в шаблонах templates/receipt_standard.html и templates/receipt_compact.html, а также обнови main.py для генерации QR-кода:

1. Логотип компании (в шапке чека):
   - Добавь аккуратный минималистичный векторный логотип (inline SVG) и блок с реквизитами вымышленной компании (название, ИНН, адрес, телефон).

2. Динамический QR-код (в нижней части чека):
   - Добавь библиотеку qrcode[pil] в requirements.txt и установи её.
   - В main.py перед рендерингом шаблона генерируй QR-код, содержащий строку с номером чека, датой и итоговой суммой (например: "Чек №{invoice_id} | Дата: {date} | Итого: {total} руб.").

3. Печать организации и подпись (в подвале стандартного чека receipt_standard.html):
   - Сверстай блок "М.П. / Подпись ответственного лица" и наложи поверх него полупрозрачную круглую синюю печать организации (реализованную через inline SVG с текстом по кругу, легким поворотом transform: rotate(-12deg) и opacity: 0.75).

4. Улучшение верстки и CSS:
   - Настрой поля страницы через @page { size: A4; margin: 15mm; } для стандартного чека и узкий формат @page { size: 80mm auto; margin: 5mm; } для кассового чека.
